# @kept/core

Provable payment promises in pure TypeScript (Node, browsers, edge, Convex). Zero runtime dependencies besides the audited `@noble` crypto libraries.

```bash
npm i @kept/core
```

```ts
import { verify, renderContract, logoNaive, logoFixed } from "@kept/core";

const r = verify(logoNaive, { feeBps: 250 });
r.ok;                       // false
r.properties.find(p => p.status === "violated")?.counterexample?.steps.map(s => s.narration.join(" "));
// 1. Funding is confirmed … releases $100.00 to the payee.
// 2. The payee submits “Final logo (SVG)” before “Delivery deadline”.
// 3. “Delivery deadline” passes … refunds $200.00 to the funder. … settles.

verify(logoFixed).ok;       // true: conservation, no stuck money, every promise, PayPal window
renderContract(logoFixed).rules;   // plain English, generated by code
```

What's inside:
- `validateContract`, `irHash`, `termsHash`: the contract language (`ContractIR`) and content addressing
- `verify` / `verifyContract`: exhaustive BFS model checker returning shortest counterexamples, every outcome, money/time bounds and a PayPal lifecycle plan
- `step`, `initialState`, `enabledEvents`: the deterministic interpreter the runtime executes
- `renderContract`, `describeClause`: deterministic plain English
- `feeForRelease`, `authorizationAmount`, `formatCents`: integer money math
- `sealJournalEntry`, `verifyChain`, `signReceipt`, `merkleRoot`, `inclusionProof`, `verifyInclusion`: signed hash chains and an RFC 6962 transparency log
- `validateMandate`, `evaluateSpend`, `verifyMandate`: AI agent spending mandates
- `SPEC_OUTPUT_SCHEMA`, `CLAUSES_OUTPUT_SCHEMA`, …: JSON Schemas for LLM structured outputs
- `EXAMPLES`: reference contracts, including two drafts with real bugs

See the [contract language](../../docs/02-CONTRACT-LANGUAGE.md) and [verifier](../../docs/03-VERIFIER.md) docs.
